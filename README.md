Sports Analytics
Monte Carlo simulations for a constructed 2026 Formula 1 season, and a linear regression model for NFL rushing yards.

Projects:
f1-2026 — Championship, Constructors, and Runner-Up (P2) title odds, simulated from a weekly tracker.
nfl-rushing-yards — Predicting final-season rushing yards from Weeks 1–2, with weekly tracking for five running backs.

How to run:
Each project folder is self-contained. Keep the notebooks in the same folder as their data files, then open the notebooks in Jupyter and run them top to bottom.
